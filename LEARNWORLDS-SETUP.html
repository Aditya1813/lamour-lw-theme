Installing the L'Amour theme on LearnWorlds

One stylesheet and one script re-skin the whole white-label school in the redesigned site's design system. After this setup, changing the design never means opening LearnWorlds again.

The idea in one line. LearnWorlds holds four lines of code. Everything else lives in ~/dev/lamour-lw-theme, in git — so a design change is ./build.sh and a push, not a copy-paste into a text box in a web app.

01Pick where the files are hosted

LearnWorlds will load two files by URL. They need to sit somewhere public with permissive CORS. Three realistic options:

OptionSetupDeployVerdict
GitHub Pages New public repo, Settings → Pages → deploy from main git push, live in ~30s Recommended Free, already have the account, short cache.
Cloudflare Pages Connect the repo once git push, live in ~15s Marginally faster. Worth it only if you're already in Cloudflare.
jsDelivr from GitHub Nothing beyond a public repo git push, then up to 12h cache on @main Avoid for active work — you'd have to tag a version per change.

The existing lamour-website repo is private, so it can't serve these. Use a separate public repo — it contains only CSS and JS, no content and no keys.

Publishing it

cd ~/dev/lamour-lw-theme
./build.sh
git init && git add -A && git commit -m "L'Amour LearnWorlds theme layer"
gh repo create lamour-lw-theme --public --source=. --push
gh api -X POST repos/:owner/lamour-lw-theme/pages \
  -f 'source[branch]=main' -f 'source[path]=/'

Your two URLs are then:

https://aditya1813.github.io/lamour-lw-theme/dist/lamour.css
https://aditya1813.github.io/lamour-lw-theme/dist/lamour.js

02Paste four lines into LearnWorlds

In LearnWorlds: Website → Design → Edit Website → Site → Site custom code.

Paste the block below into both <head> logged out and <head> logged in:

<link rel="preconnect" href="https://api.fontshare.com" crossorigin>
<link rel="preconnect" href="https://cdn.fontshare.com" crossorigin>
<link rel="stylesheet" href="https://api.fontshare.com/v2/css?f%5B%5D=sentient@300i,500i&f%5B%5D=general-sans@200,300,400,500,600,700&display=swap">
<link rel="stylesheet" href="https://aditya1813.github.io/lamour-lw-theme/dist/lamour.css?v=1">
<script defer src="https://aditya1813.github.io/lamour-lw-theme/dist/lamour.js?v=1"></script>

The course player never receives the <head> slot. It is the one documented exception. To reach it, paste the same two lamour.* lines (the stylesheet and the script — the font lines too) into <body> logged in as well. Browsers honour a <link> in the body, and the duplicate on ordinary logged-in pages costs nothing: the file is already cached.

03Paste the forms stylesheet by hand

Sign-in, sign-up and checkout forms render through a separate slot that the <head> stylesheet doesn't reach. Copy the whole of dist/lamour-dynamic-slot.css into:

Site custom code → <style> Dynamic (css)

It's ~35 lines and it changes rarely, so hand-pasting is fine here. It is the only slot you'll ever have to re-paste.

04Turn off what would fight it

The stylesheet uses !important to beat LearnWorlds' inline styles, but it can't beat colours you set on individual elements in the builder. Before checking your work:

  • Theme Explorer → Typography — leave whatever font is set; the stylesheet overrides it. Don't bother uploading Sentient/General Sans as custom fonts, Fontshare already serves them.
  • Theme Explorer → Colours — set brand, accent 1 and accent 2 all to #0B0B0A. The theme collapses them to ink anyway, and matching them means the builder's own previews stop lying to you.
  • Per-element colour overrides — any text or button where someone picked a colour in the sidebar will keep it. Clear those as you find them.

05Check it

Open the school and confirm, in this order:

  1. Headings are Sentient italic, body is General Sans. If not, the Fontshare line didn't paste or the CDN URL is wrong.
  2. Buttons are square, uppercase, tracked, no underline.
  3. Sections have the tall fluid padding, not the template's default.
  4. Log in and open a course — the player should have the fonts. If it doesn't, step 02's body-slot paste is missing.
  5. Sign out and open the sign-in page — inputs should be hairline underlines. If not, step 03 is missing.

06How you change it from now on

cd ~/dev/lamour-lw-theme
# edit src/*.css
./build.sh
open http://localhost:8791/preview/index.html   # after: python3 -m http.server 8791
git commit -am "…" && git push

Live within a minute. The only time you touch LearnWorlds again is to bump ?v=1 to ?v=2 in the head slots, and only if a browser is stubbornly holding an old copy.

07Building pages

There are two ways to put a section on a page, and the order matters.

First choice — LearnWorlds' native widgets

Heading, text, button, image and column widgets all come out on-brand automatically, because the stylesheet targets LearnWorlds' own class names. A page built this way stays editable by someone who doesn't write code, which is the whole point of being on LearnWorlds. Two classes are worth knowing — add them to a section in the builder's section settings:

ClassEffect
la-stoneWarm neutral band instead of white — use it to alternate sections.
la-inkBlack section; every child re-reads its colours, no per-element picking.
la-bleedOn a full-bleed photo section: removes the padding so the image is the section.

Second choice — the block library

For the few layouts the builder can't make. Add an HTML widget to a section and paste the file's contents:

FileWhat it is
blocks/01-hero.htmlFull-bleed photograph, ink veil, headline on the lower third
blocks/02-stats.htmlCourse-structure figures that count up once on entry
blocks/03-journey-spine.htmlNumbered enrol → aftercare sequence
blocks/04-pull-quote.htmlFull-bleed attributed quote
blocks/05-editorial-split.htmlImage one side, text the other
blocks/06-cta-band.htmlClosing call to action, two actions maximum
blocks/07-accreditation.htmlText-only approval strip
blocks/08-course-index.htmlHairline course list, prospectus-style

Two claims rules are baked into the blocks and must survive editing.

The stats block carries course-structure figures only — never a graduate or student count. The accreditation strip's wording is a placeholder marked REPLACE: put the approved wording in word for word, don't paraphrase it, don't shorten it, and don't put a guarantee anywhere near it. No third-party logos.

Images

Upload through LearnWorlds' own image library and use the URL it gives you — it looks like https://lwfiles.mycourse.app/6a9a7a4771cb6116e364cb52-public/…. That's your school's CDN and it's the right place for photography. The theme repo hosts CSS and JS only; don't put images in it.

08Reference: what LearnWorlds actually gives you

Worth knowing when you want to do something this setup doesn't cover.

SlotScopeTakes
<head> logged in / logged outEvery page of the templateHTML + liquid
<body> logged in / logged outEvery page — and the course playerHTML + liquid
<style> DynamicSign-in / sign-up / checkout formsCSS
<style> built-in pagessocial, profile, workpad, account…CSS
<body> after purchase / after registrationPost-conversion onlyHTML + liquid
Page slotsOne page — same six shapesHTML / CSS
Selected element → Edit HTMLOne element on one pageHTML

Two hooks the theme leans on heavily, and you can too:

  • body.slug-{slug} — every page carries its slug as a body class, so body.slug-account p { … } targets one built-in page. Built-in slugs: social, profile, workpad, account, dailynews, people, inbox.
  • Liquid — {{USER.NAME}}, {{REQUEST.SLUG}}, {% if USER.TAGS contains 'x' %}, {% unless REQUEST.IS_COURSE_PLAYER %}. Conditionals need the Learning Center plan or higher. Useful for things like showing an alumni-only band to tagged users without building a second page.

09If you'd rather not host anything

It works without a CDN: paste the entire contents of dist/lamour.css inside a <style>…</style> in the head slots, and dist/lamour.js inside <script>…</script>. It's ~37 kB, which LearnWorlds accepts.

The cost is real, though: every change means re-pasting into four slots by hand, there's no version history, and there's nothing stopping the four copies from drifting apart. Take this route only if hosting is genuinely blocked.
